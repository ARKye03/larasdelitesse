# Larasdelitesse

ReactJS, Laravel, SQLite, E-commerce web application

## Development

```sh
git clone https://github.com/ARKye03/larasdelitesse.git; cd larasdelitesse
```

```sh
pnpm install
```

```sh
php artisan migrate
```

```sh
composer run dev
```
